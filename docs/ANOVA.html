17  Compare 3+ Groups

ANOVA, Kruskal-Wallis, and ANCOVA

Author

Shane McCarty, PhD

Published

09.20.2026

Abstract

This chapter shows researchers how to compare the average score of three or more groups with a one-way ANOVA, how to find out which groups differ with a Tukey follow-up test, how to use the Kruskal-Wallis test when the outcome is not normal, and how to add a covariate with an ANCOVA.

Keywords

ANOVA, ANCOVA, Tukey, Kruskal-Wallis, covariate, comparison

Resources Ref’s kickoff: find the Ref before you code

Open Project → Open .qmd → Run load-library chunk → Run All Chunks Above → code. If anything looks wrong, use Ref’s Quick Checklist.

17.1 When do you use this chapter?

Your research question is a comparison, and you have three or more different groups and one continuous outcome.

Test Use it when
ANOVA three or more groups, outcome is normal
Kruskal-Wallis three or more groups, outcome is not normal
ANCOVA an ANOVA, plus one continuous variable you want to account for (a covariate), such as age
GoGo: Do these two things first
  1. Check whether your outcome is normal in Describe Your Data.
  2. Make the barplot or violin plot in Visualize a Comparison.

17.2 The example data

The example uses the lab dataset and two questions.

  • Normal outcome (ANOVA and ANCOVA): do people in poor or fair, good, and very good or excellent general health differ in well-being (WELLBEING)?
  • Outcome that is not normal (Kruskal-Wallis): do people on the political left, in the middle, and on the right differ in how much they believe mental health problems have social causes (SOCIAL)?
library(tidyverse)
source("lab_prep.R")   # creates mh_clean

mh_clean <- mh_clean |>
  mutate(HEALTH_3 = factor(case_when(
    HEALTHSTATUS %in% c(1, 2) ~ "Poor or fair",
    HEALTHSTATUS == 3         ~ "Good",
    HEALTHSTATUS %in% c(4, 5) ~ "Very good or excellent"),
    levels = c("Poor or fair", "Good", "Very good or excellent")))   # the group must be a factor

mh_clean |>
  filter(!is.na(HEALTH_3)) |>
  group_by(HEALTH_3) |>
  summarise(n = n(),
            mean = mean(WELLBEING, na.rm = TRUE),
            sd = sd(WELLBEING, na.rm = TRUE))
# A tibble: 3 × 4
  HEALTH_3                   n  mean    sd
  <fct>                  <int> <dbl> <dbl>
1 Poor or fair              36  3.03 0.673
2 Good                      81  3.19 0.598
3 Very good or excellent    61  3.56 0.662
mh_lmr <- mh_clean |>
  mutate(POL_LMR = case_when(
    POLITICALBELIEFS %in% c(1, 2) ~ "Left",
    POLITICALBELIEFS == 3         ~ "Moderate",
    POLITICALBELIEFS %in% c(4, 5) ~ "Right")) |>
  filter(!is.na(POL_LMR)) |>                 # keep only the three groups
  mutate(POL_LMR = factor(POL_LMR))          # the group must be a factor

mh_lmr |>
  group_by(POL_LMR) |>
  summarise(n = n(),
            mean = mean(SOCIAL, na.rm = TRUE),
            sd = sd(SOCIAL, na.rm = TRUE))
# A tibble: 3 × 4
  POL_LMR      n  mean    sd
  <fct>    <int> <dbl> <dbl>
1 Left        90  4.23 0.625
2 Moderate    26  4.13 0.674
3 Right       47  3.63 0.794
CautionCaution: Don’t leave your group as a number

If the group is stored as 1, 2, 3, R treats it as a score and gives you a wrong answer with no error message. Make it a factor() first.

GoGo: Check the shape of your data

aov() needs one row per person, with one column for the outcome and one column for the group. Most survey data already look like this, so there is nothing to change.

You only need to reshape when the scores you want to compare sit in separate columns (for example, score_time1, score_time2, score_time3). Then use pivot_longer() from Pre/Post Data to stack them into one outcome column and one group column. Note that the same people measured three times is a repeated-measures design, which this chapter does not cover. Talk to your instructor.

17.3 ANOVA

An ANOVA asks one question: is at least one group average different from the others?

model_anova <- aov(WELLBEING ~ HEALTH_3, data = mh_clean)
summary(model_anova)
             Df Sum Sq Mean Sq F value   Pr(>F)    
HEALTH_3      2   7.47   3.735   9.238 0.000153 ***
Residuals   175  70.75   0.404                     
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
10 observations deleted due to missingness

Read the HEALTH_3 row: F value is the test statistic, and Pr(>F) is the p-value. If p is smaller than .05, the groups are not all the same.

17.3.1 Which groups differ? The Tukey follow-up test

A significant ANOVA does not tell you which groups differ. Run the follow-up test only when the ANOVA is significant.

TukeyHSD(model_anova)
  Tukey multiple comparisons of means
    95% family-wise confidence level

Fit: aov(formula = WELLBEING ~ HEALTH_3, data = mh_clean)

$HEALTH_3
                                         diff        lwr       upr     p adj
Good-Poor or fair                   0.1652337 -0.1358327 0.4663001 0.3985811
Very good or excellent-Poor or fair 0.5258967  0.2100089 0.8417844 0.0003509
Very good or excellent-Good         0.3606630  0.1058627 0.6154632 0.0028713

Each row compares two groups. diff is the difference between the two averages, and p adj is the p-value for that pair.

17.4 If your outcome is not normal: Kruskal-Wallis

SOCIAL is skewed and does not pass the checks in Describe Your Data, so the political groups are compared with the Kruskal-Wallis test.

kruskal.test(SOCIAL ~ POL_LMR, data = mh_lmr)

    Kruskal-Wallis rank sum test

data:  SOCIAL by POL_LMR
Kruskal-Wallis chi-squared = 18.736, df = 2, p-value = 8.54e-05

The follow-up test for a significant Kruskal-Wallis test compares the groups two at a time.

pairwise.wilcox.test(mh_lmr$SOCIAL, mh_lmr$POL_LMR, p.adjust.method = "holm")

    Pairwise comparisons using Wilcoxon rank sum test with continuity correction 

data:  mh_lmr$SOCIAL and mh_lmr$POL_LMR 

         Left  Moderate
Moderate 0.499 -       
Right    5e-05 0.026   

P value adjustment method: holm

17.5 ANCOVA: add a covariate

An ANCOVA asks the same question as an ANOVA after accounting for another continuous variable. Here the covariate is age. Put the covariate first in the formula.

model_ancova <- aov(WELLBEING ~ AGE + HEALTH_3, data = mh_clean)
summary(model_ancova)
             Df Sum Sq Mean Sq F value   Pr(>F)    
AGE           1   0.40   0.397   0.968 0.326538    
HEALTH_3      2   7.28   3.638   8.879 0.000214 ***
Residuals   172  70.47   0.410                     
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
12 observations deleted due to missingness

Read the HEALTH_3 row the same way as before. It now means “do the groups differ, for people of the same age?”

CautionCaution: Three things to know about ANCOVA
  • The order in the formula matters in aov(). The covariate goes first, and the group goes last.
  • People who are missing the covariate are dropped, so your n can get smaller. Check it with nobs(model_ancova).
  • An ANCOVA is a linear regression with a categorical predictor. See Relate 3+ Variables for how to read slopes and check residuals.

17.6 Report it

A one-way ANOVA showed that ________ (differed / did not differ) across ________ groups, F(__, __) = ___, p = ___. A Tukey follow-up test showed that ________ scored higher than ________ (p = ___).

For an ANCOVA, add: “after accounting for ________”.

CautionCaution: Different does not mean caused

A survey comparison tells you that groups differ. It does not tell you why. Write “differed” or “scored higher”, not “caused” or “led to”.
